# Pokédex React

Sitio web desarrollado para el Trabajo de Presentación del sitio Web de Programación Web II.

La aplicación está realizada con React, JSX y Vite. Permite consultar Pokémon mediante la API pública PokéAPI, buscar por nombre o número, filtrar por tipo, recorrer una colección local y enviar mensajes desde un formulario de contacto integrado con EmailJS.

El proyecto utiliza componentes reutilizables, `useState`, `useEffect`, props, destructuring y React Router. También incluye un mapa en la página de contacto y está preparado para ejecutarse en GitHub Pages.

```bash
pnpm install
pnpm dev
```

Para generar la versión de producción:

```bash
pnpm build
```
